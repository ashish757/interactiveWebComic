- This interactive web comic features a story from Harry Potter in Indian style and in fast forward way. 
- About the interactivity, I have added dynamic dialogues, some subtle animations and more character based animation coming soon. 
- I have also added some minigames and puzzles for interactions and unlocking new paths in the story. 
 Your responses and results of the game decide which path you are gonna go in the story. 
- This also has audio support which will be implemented completely pretty soon.
